# Frank Vera — Engineering Portfolio

Futuristic JARVIS-inspired portfolio for Frank Vera, a Georgia Tech Mechanical Engineering student interested in automotive, aerospace, robotics, and advanced engineering systems.

## Live website
https://frvnk-v3ra.github.io/

## Files
- `index.html` — website content and links
- `style.css` — visual styling and responsive layouts
- `script.js` — mobile navigation and footer year
- `assets/` — reserved for future project images and resume

## Updating the website
Upload the updated files to the root of the `main` branch in your existing `frvnk-v3ra.github.io` repository. Commit changes. GitHub Pages automatically redeploys.

## Future improvements
Add project photos, engineering calculations, case studies, and a resume. Share RoboJackets team files only with permission.

Built with HTML, CSS, and vanilla JavaScript.
