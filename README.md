# Engineering Portfolio — Futuristic / JARVIS-inspired

A lightweight, responsive mechanical engineering portfolio made with HTML, CSS, and vanilla JavaScript. No dependencies or build step.

## Preview locally
Open `index.html` in a browser.

## Publish on GitHub Pages
1. Create a public repository named `YOUR-USERNAME.github.io` (replace with your actual GitHub username).
2. Upload `index.html`, `style.css`, `script.js`, and the `assets` directory to the repository root.
3. In the repository, visit **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**; select `main` and `/ (root)`; save.
5. Visit `https://YOUR-USERNAME.github.io/` after GitHub finishes deploying.

## Customize before sharing
- In `index.html`, change the page title, introduction, and about paragraph.
- Replace GitHub and LinkedIn placeholder links with your actual public profile URLs.
- Add `assets/resume.pdf` and set `data-ready="true"` on the Resume link. Otherwise the button displays a reminder.
- Replace project card placeholder links with repository URLs and remove their `data-placeholder="true"` attributes.
- Replace the stylized SVG project illustrations with your own project images when available.
- Update project status and skill descriptions so every claim is accurate.

## Privacy and team project reminder
Only publish CAD files, photos, code, and documentation you own or have permission to share. Avoid publishing sensitive contact details, secrets, tokens, and private team information.
